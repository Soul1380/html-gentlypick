视频下载组件来源：

- yt-dlp： https://github.com/yt-dlp/yt-dlp ，官方 Windows release；下载时与官方 SHA2-256SUMS 核对。许可证见 https://github.com/yt-dlp/yt-dlp/blob/master/LICENSE 。
- FFmpeg / ffprobe： https://github.com/yt-dlp/FFmpeg-Builds ，官方配套 Windows GPL 构建，源码与构建脚本见该仓库及 https://github.com/FFmpeg/FFmpeg 。附带 FFmpeg-LICENSE.txt。

这些组件仅由程序对所选公开播放链接调用；不使用浏览器密码库，不下载整个播放列表。
