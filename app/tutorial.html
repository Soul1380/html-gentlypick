轻摘使用教程

想做什么，从这里开始

不用先弄懂所有设置。选一个目标，照着箭头走一遍。

下面的示例可以照填，也可以一键带到任务草稿中。
先看一遍一个网址找多篇文章图片与下载生成报告AI 与模型整理视频保存与返回更新与备份解决问题

01

先认清：轻摘把什么变成什么？

把网页和文件收进来，再按你的目的整理。收集和 AI 分析是两步。

  1. 找到素材文章网址、搜索主题或视频
  2. 采集并核对在“摘录档案”看实际收到的内容
  3. 整理成报告选资料，按需要使用 AI
  4. 保存或导出保留原文、来源和整理结果
我已经有文章链接直接摘录这篇文章 →我只有一个主题在指定网站找多篇文章 →我想整理视频内容视频 → 文字 → 图文时间轴 →
几个名字先说清：“任务”是一次收集计划；“摘录”是已经收到的内容；“分析报告”是对这些内容的整理。保存任务后，还需要点击任务卡上的“搜索并摘录”或“立即摘录”才会开始收集。
02

已有一个文章网址：把正文摘下来

适合收藏新闻、教程、产品介绍等你能打开的网页。

  1. 监测任务右上角点“新建任务”
  2. 选文字文章入口类型选“直接 URL”
  3. 粘贴文章链接不是搜索结果页中的标题文字
  4. 保存 → 立即摘录完成后去“摘录档案”查看
任务名称 · 方便你自己找我收藏的电池技术文章
文章链接 · 换成你在浏览器里打开的原文https://example.com/news/001这是格式示例，不是可采集的真实新闻。请粘贴你自己的文章地址。

成功后应该看到什么？

文章标题、正文和来源链接。先点开一篇看看内容完整不完整，再决定是否交给 AI。

需要登录怎么办？

按任务提示到采集浏览器完成登录，再重试。平时用的 Chrome 登录状态，不一定与采集窗口共用。

03

只有一个主题：一次找多篇文章

你告诉轻摘“找什么”和“允许去哪些网站找”，它再把找到的文章收进同一个项目。

  1. 输入主题例如：新能源汽车 电池 技术进展
  2. 限定网站例如：新华社网站
  3. 保存并运行先少量测试，确认方向正确
  4. 按项目查看一组文章，不用重新逐篇寻找

亲手填一次，看看流程

安全演示 · 不联网、不调用 AI
网站范围一行一个。主题不是网址，不要填在这里。
  1. 填写计划任务名称、主题与范围
  2. 保存任务实际使用时要点保存
  3. 运行任务运行后才会联网查找
  4. 查看结果到摘录档案核对原文
改一改上面的内容，再点击“演示这个过程”。“填入草稿”只帮你填表，不会保存或运行任务。
“深入查找”是怎么回事？

普通收集先处理找到的页面。开启深入查找后，会继续点页面里已经出现的文章链接或相关推荐。层数越多、页面数量越大，等待越久；它不会无限查完整个网站。

04

收图片、下视频、找评论和附件

新建任务时，先把“采集内容”选对。下载视频和分析视频内容是不同的事情。

图片 / 图集

图片列表或图集网址 → 选择图片采集 → 设置数量 → 运行 → 在结果中查看图片。

页面需要滚动后才显示图片时，可以尝试浏览器渲染和滚动设置。

视频下载

视频或列表网址 → 选择视频 → 设置数量与文件大小 → 运行 → 打开下载位置。

下载只保存视频。要把视频整理成要点，请继续看“整理视频”。登录、权限和站点限制仍可能让下载失败。

B 站评论

普通 BV / av 视频链接 → 选择评论 → 设置数量、排序 → 运行 → 查看或导出表格。

适合整理常见问题和观众反馈；番剧、电影页面不是这项功能的普通视频入口，也不能保证得到全部评论。

网页附件

包含附件链接的网页 → 选择附件 → 决定是否下载文件 → 运行 → 查看结果。

可收集网页里能找到的 PDF、Word、Excel 等附件链接；隐藏在复杂按钮后的文件可能找不到。
结果少于预期时，先看任务明细里的失败、重复和超限原因。不要马上把数量加到很大。
05

一组文章，怎样变成一份报告？

先收集，再选择。你不必在长列表里一篇篇勾选整个项目。

  1. 打开“分析报表”点击“选择摘录项目与文章”
  2. 勾选整个项目也可以展开，只选其中几篇
  3. 选报告类型整理要点、做对比或提取数据
  4. 生成 → 核对 → 导出保留来源与原文证据

基础整理

先做程序能完成的提取和统计，不需要先配 AI。适合检查资料有没有收对。

AI 分析

需要先配置并测试模型。资料较多时会分批处理；失败后可以重试没有完成的批次。

AI 的结论要对照来源看。当前单次最多选 1000 篇，每篇最多取前 8000 字；超长文章后半部分的细节可能没有进入分析。分批结果也不等于已经做过所有文章之间的综合比较。
06

AI 怎么接上？先选本地，还是在线

DeepSeek 等文字模型负责读文字、整理内容；Whisper 负责把声音转成文字。两种用途不要选反。

用电脑里的模型

先在“本地模型”确认服务已运行、模型可用，再到 AI 设置中选择“本地模型 · Ollama”。

  1. 启动或补全 Ollama 运行环境
  2. 已有模型文件就导入；没有再下载
  3. AI 设置选 Ollama 和对应模型
  4. 勾选启用、保存，再测试
本地 Ollama 通常不用填写 API 密钥。首次使用要加载模型，可能等得更久。

用服务商提供的在线 AI

从服务商控制台取得完整接口地址、模型名称和密钥，按原样填进 AI 设置。

  1. 选择服务商
  2. 核对完整接口地址和模型名称
  3. 填写密钥，勾选启用及发送授权
  4. 保存设置 → 测试接口
费用和可用模型以服务商控制台为准。不要把密钥发给别人或放进截图。

“下载好了”和“能选来用”差在哪？

GGUF 文件在磁盘上→ 导入 →出现在可用模型列表→ 选择 →AI 设置或视频分析调用它
已经导入过，不要一出问题就重新下载。先看 Ollama 是否运行、是否读取原来的模型目录。刷新只重新读状态，不会重新安装或导入模型。
安装 Whisper 时怎么填？

选择一个版本，设置保存目录，点“自动查找”找 Python。找到后再安装。进度分为准备环境、安装组件、下载模型、校验模型；没有百分比的阶段也可能正在正常处理。电脑没有 Python 时，需要先准备 Python，或填写已有的 python.exe 路径。

小版本通常下载更快、占用更少；是否换更大的版本，应看自己的电脑和实际转写效果，不必一开始全装。

07

把视频整理成“文字＋截图”

第一次建议用短视频练习，先让转写成功，再做 AI 整理。

  1. 导入视频点击文件夹图标选择本机文件
  2. 选择转写方式例如已安装的 Whisper
  3. 仅转写，先检查看看人名、数字有没有听错
  4. 分析与导出查看时间轴，调整截图再保存

我已经有字幕

直接导入 SRT / VTT 字幕 → 选择文字分析模型 → 分析已有转写。这样可以跳过声音识别这一步。

我想先看看转写准不准

先选“仅转写”。确认文字后再点“分析已有转写”；不必每次都从头处理视频。

当前视频分析支持 20 分钟以内、300 MB 以内的视频。长视频请先分段。这里的限制与“视频下载任务”的文件大小设置是两回事。
08

文件在哪？怎么选目录、怎么返回？

输入框右边的文件夹图标是浏览位置，不是保存按钮。

D:\轻摘资料\报告📁
  1. 直接输入或粘贴路径例如 D:\轻摘资料\报告
  2. 点文件夹或按 Enter在大窗口里输入地址、选文件夹
  3. 点击“应用路径”设置页中，确认后才正式保存

已有文件要不要一起搬？

应用目录时，按弹窗选择。选择不转移，之后保存到新位置，原文件保留在旧位置；手动移动文件后，旧记录可能需要重新定位。

打开管理窗口后怎么回去？

点“← 返回”或关闭窗口，回到原输入页面。左侧选项卡则是在右侧主区域换页，不是打开小窗口。

页面切换会保留本次运行中的输入草稿。关闭软件后，未保存草稿和 API 密钥会清空；普通设置请点击保存。不要把还没保存的输入当成已经保存。

滚动条只在滚动或拖动时出现，停下后收起；鼠标滚轮、Page Up / Page Down 仍可以正常翻页。

09

升级前后，怎样保留自己的资料？

日常使用者不需要拿源码文件操作。

  1. 先等任务完成不要中途打断下载或分析
  2. 版本与更新点“检查更新”
  3. 按提示完成升级需要时关闭主窗口
  4. 重新打开核对看任务、资料和模型状态
最重要的本机资料文件夹UserData它在轻摘程序目录里。完整复制这个文件夹可备份任务、摘录和软件内的登录资料。单独存放的模型还需要单独保留。
换目录或换电脑前，先退出软件并保留旧目录。不要用新的空 UserData 覆盖旧资料。确认新版能正常读取后，再决定是否处理旧版本文件。
如果你是发布者，要把软件给别人用

使用完整的“GitHub 上传文件”目录，先运行检查脚本，再运行发布脚本。上传后还要等 GitHub 构建成功；成功发布安装程序和更新包后，新用户才能下载，旧用户才能检查更新。不要只把安装程序复制到源码目录，也不要给更新包随便改名。

10

遇到问题，先看哪一处？

先看实际状态和错误原文，再决定改什么。不要反复下载或把所有开关一起改掉。

采集不到文章

打开任务明细 → 看失败网址 → 检查链接是否能打开、网站范围是否正确 → 需要时登录或尝试浏览器渲染 → 少量重试。

模型明明下好了，却选不到

本地模型 → 看服务是否运行 → 确认模型是“可用”还是“待导入” → 检查原模型目录。已导入的模型先恢复连接，不要立即重新下载。

AI 一直等待、最后超时

AI 设置先测试接口 → 确认模型名和地址 → 本地模型等首次加载完成 → 必要时调整等待时间 → 重试未完成的批次。

下载进度暂时不动

看当前是安装组件、下载还是校验 → 展开安装详情 → 查看网络错误或等待提示。停止任务前先确认是否仍在写入文件。

视频里说的话没转出来

先确认视频有声音 → 核对“语音转文字”设置 → 用短片段仅转写测试。文字模型负责整理，不会替代语音识别。

点管理以后，以为输入不见了

先点窗口上的“← 返回”。页面内管理与左侧页面切换不同；如果已经完全退出软件，未保存的草稿不会保留。

示例只用于学习操作。实际结果以任务明细、原文内容和服务返回为准。
