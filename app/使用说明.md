# 轻摘：最小网页摘录工具

## 视频数量只计合格结果

开启自动下载时，“每次目标”按成功下载并完成媒体校验的新视频文件计数。超出大小上限、下载失败、仅保存封面/信息都不占数量；已有重复记录也不计新增，继续检查后续候选补足目标。单次最多检查100条候选（根据目标动态设定为至少20条、目标的5倍，上限100）；候选耗尽或达到检查上限时，明细说明未补足多少。未开启文件下载的“仅信息”任务仍按明确选择的信息报告计数。

摘录档案默认只显示合格摘录。未完成的视频保留在“未完成视频”页签，供查看原因或重新下载，不混入正式摘录数量。已有失败报告不删除，原始失败明细仍可追溯；成功重试后可回到“已摘录”列表。

## 下载路径与大小诊断

视频报告中可以展开“查看具体下载路径与音视频源”，查看搜索来源、二级播放页、音频/视频源域名、各流大小及本机目标 MP4 路径。带签名的临时流 URL 不作为可长期复用链接展示。

下载前先读取所选清晰度的流信息，比较音视频合计大小与上限。默认统一为500MB，不再使用隐藏的300MB单流限制；任务和单篇报告均可调整为100至20480MB。超限会明确报出预计大小与上限，并停止下载。大文件仍受10分钟任务下载超时限制。多P视频当前仅下载默认分P，页面标题中的“十小时合集”不等于一个单独文件；路径诊断中显示实际选中的分P标题和时长。不会为了下载自动购买权限或降低目标画质。

## 1080P 与二级播放页

视频搜索结果只用于提取卡片链接，不把封面当作视频。程序逐个打开二级播放页，解析视频数据后才调用下载组件。明细标记搜索来源、二级播放页、已打开/已解析/已下载文件数；渲染后的页面丢失初始化数据时会回退读取同一播放页的原始数据。

现在支持最高1080P，新增任务默认1080P，可选择360/480/720/1080。下载选择不高于目标的当前可访问流，并在合并后读取文件真实宽高、音轨和时长。报告显示实际分辨率；若只能取得较低分辨率，会提示与目标不同，不通过放大低清视频伪造高清。视频平台的账号、会员或访问限制仍可能影响可下载的画质。

## 视频信息采集（哔哩哔哩参考适配）

已支持下载实际视频文件：新视频任务可勾选“自动下载实际视频文件（含音频）”，选择360P、480P或720P；已有报告可点击“下载360P”或“下载最高720P”。下载完成后直接显示本地播放器和“下载MP4文件”。使用随附 yt-dlp 获取当前可访问的音视频流，FFmpeg 合并为 MP4，ffprobe 校验后才标记成功。下载进度、失败原因保留在对应报告中。不读取日常浏览器账号，不处理付费或不可访问的清晰度。单流下载上限300MB，最终文件上限500MB，超时10分钟。文件保存到 videos 目录，并支持浏览器按字节范围播放。

“采集内容”选择“视频信息 / 视频网站”。单 URL 入口可填首页、视频列表或播放页；搜索入口可填 `https://search.bilibili.com/video?keyword={{query}}`，填写哔哩哔哩首页时也会构造该搜索地址。默认采用普通网页请求，每次最多10个视频，可设1至30个；遇到动态页面或登录限制可开启浏览器渲染，或通过任务卡的登录辅助沿用临时登录会话。

对哔哩哔哩，先识别并去重 `/video/BV…` 或 `/video/av…` 链接，再从播放页 JSON 视频数据提取标题、封面、UP主、时长、发布时间、播放量、点赞量与简介。不执行页面内的 JSON 赋值脚本，仅解析 JSON；没有可靠视频数据时会报错，避免误把版本提示页等当视频。其他站点先尝试标准 VideoObject 元数据，尚未保证全平台兼容。

每个视频独立报告，保留原站播放链接和封面，按任务与批次归档；可在原网站观看，也可下载实际MP4。当前不提取字幕、不做语音转写和内容分析。评论、弹幕、相关推荐不作为视频简介保存。统计值是采集时快照；仅播放量等变化不会重复生成新报告，标题、简介、封面或模板变化时会生成新版本。下载组件与来源说明见 tools 目录。

## 手动登录后继续图片采集

图片任务卡点击“打开网页登录 / 验证”，弹出独立的可见采集浏览器。请本人在该窗口正常登录网站、完成网站要求的验证，再回工具点击“我已登录，继续采集”。程序使用同一个浏览器上下文访问列表、详情和图片文件，复用该会话适用于对应域名的 Cookie，不读取日常浏览器账号，不填写密码或自动解决验证码。

登录窗口保持打开；“关闭登录会话”会结束会话，任务与摘录仍保留。账号状态仅保留在运行中的临时浏览器，不导出 Cookie 到任务文件或上传服务器。服务重启、浏览器关闭后需要重新登录。定时任务不能依赖已关闭的登录窗口，也不会在后台自行弹出登录窗口。登录网页可能跳转到网站的认证服务；采集开始后恢复任务网站范围限制。

## 图片素材采集（列表 → 二级详情 → 大图）

新建或编辑任务，在“采集内容”选择“图片素材 / 图片搜索站”。这与资讯深度模式分开，专门处理图片瀑布流和详情页，默认打开二级详情页并启用浏览器渲染。

- “打开二级详情页”开启时识别带图片的卡片链接；花瓣还支持 `/pins/数字` 和 `data-pin-id`，会合并同一卡片的跟踪参数和重复链接。每次最多处理1至30个详情页，每个详情保存1至10张图片。不会继续爬详情页的相关推荐。
- 关闭二级详情时，只摘录当前列表页中的图片；不会把列表缩略图冒充详情大图。详情页优先采用页面提供的 original/full 地址、元信息图和较大尺寸图片，但不保证总能拿到原始分辨率。
- 浏览器渲染使用独立临时 Edge 会话，不读取日常浏览器登录状态。默认最多滚动一次加载更多卡片，可设0至3次。会保留每轮已看到的卡片以适配瀑布流。只处理当前可加载到的有限结果，不保证搜全。
- “详情链接路径特征”可以填 `/pins/`，限制只打开这种路径。列表及详情必须在指定网站范围内，图片文件可来自该页面引用的图片 CDN。图片下载沿用5MB/张、40MB/报告上限，图片保存到本机；全部下载失败时不生成成功报告。
- 搜索入口可填写 `https://huaban.com/search?q={{query}}`，提示词会填入 query；花瓣域名首页也会转换为该搜索地址。其他网站应填写真实搜索页或带 query 占位符的地址。图片任务不通过文章搜索引擎检索、不用正文关键词过滤图片，也不进行图片语义识别。
- 摘录档案中保留任务和批次分组，图片结果显示缩略预览，打开后优先显示保存的图片，再展开来源记录。每条记录含列表页、详情页与图片文件 URL，可追溯和导出图文 HTML。

图片浏览器优先使用本机 Codex 自带 Playwright；其他电脑可安装 Node.js 及本目录 package.json 中的可选依赖，然后安装 Microsoft Edge 或 Playwright Chromium。不使用图片模式时无需浏览器依赖。

此功能已通过动态卡片 → 二级详情 → 图片文件的实际 Edge 测试；2026年11月1日本机对花瓣的小范围实测返回 HTTP 405，因此当前不能声称已解决花瓣的访问限制。网站登录、验证码、反自动访问和图片下载限制仍可能阻止任务，失败会进入网站适配反馈。

## 网站适配反馈与配套分析服务

左侧“网站适配”查看不能摘录的网站。正文为空、浏览器验证、登录/访问限制及网络异常会分类记录，同站同路径同问题归并，保留出现次数。网址移除账号密码、片段、跟踪和未知查询参数，仅保留 q/query/keyword/keywords/search/id 等复现所需字段；这些字段仍可能包含搜索词，请勿提交敏感搜索或私人网址。

双击启动脚本会附带启动本机分析服务（127.0.0.1:3921），并与摘录工具连接；这不是已上线的多人云端。自动上传默认关闭，可在“网站适配”勾选；开启后仅提交公开示例网址和失败类型/错误，不上传登录凭据、正文、图片。网络异常和限流不自动提交。也可逐条“提交服务器”。首次创建的本机反馈存入 data.json，服务端分析任务和已发布规则存入 adapter-service-data.json。

配套服务接受网址后，会在独立队列中请求公开页面，识别验证、登录、访问限制，并尝试静态 HTML 图片和内嵌 JSON 图片提取。只有实际样本提取到图片才发布声明式规则。浏览器验证页面（例如花瓣当前返回的 EO_Bot_Ssid 验证脚本）会标记“等待浏览器适配”，不会伪造成功。通用正文已可用时不重复发布规则；自动分析不能保证为任意网站生成有效方法。规则测试目前验证的是图片 URL 提取，不保证图片文件可下载，也不涵盖全站所有页面。

客户端可手动同步，或开启每15分钟自动同步规则和服务端状态。规则仅包含精确域名、路径范围、内置方法类型和版本，不接受 JavaScript 或任意可执行代码。只有发布且测试通过的规则能安装；不会降级版本。同步后状态是“有新规则待重试”，只有在该示例实际重试成功后才标记“已验证可摘录”。图片格式支持 HTML 图片、JSON 图片 URL；需要运行浏览器、登录或专有 API 的方法仍需开发专用受控适配器。

以后部署远程分析服务时，在启动环境配置 SITE_ADAPTER_SERVICE_URL（HTTPS）及 SITE_ADAPTER_SERVICE_TOKEN；已有远程地址时不会启动本机配套服务。服务端可独立运行 `node adapter-service.cjs`，默认仅监听本机。要改变监听地址，用 ADAPTER_SERVICE_HOST，非本机监听必须配置令牌。服务端拒绝本机、内网和保留地址，限制重定向/响应体大小并固定已验证的 DNS 地址。当前配套服务是单部署原型，正式多人发布仍需部署、用户权限、限流、审计、域名授权与更广泛的样本测试；未在本次工作中上线公网服务。

## 摘录档案与个人偏好

摘录档案使用三栏：任务文件夹、批次和文章列表、图文详情。不同任务的文章分开显示，可按运行批次筛选或在当前任务内搜索。新运行会记录唯一批次编号；旧报告与手动导入仍保留在对应任务下，标记为无精确批次归档。没有新增文章的运行也会保留批次状态。删除任务后，其摘录仍可查看。

“搜索偏好”默认关闭个人记录与联网互通。开启个人记录后，仅在已保存搜索任务完成、并有成功或重复结果时学习关键词及词条共现。草稿、仅保存未运行、失败、无匹配不学习。每个任务相同主题和网站配置仅学习一次，防止每日执行重复加权；不会回溯导入之前的运行。偏好独立于手动主题词库，显示个人词云、学习记录，并向提示词编辑区提供“偏好联想”。关闭停止新增学习；清空操作删除个人记录和词频，不影响任务与摘录。记录最多保留最近1000次配置学习，词频为累计统计。

当前交付没有连接或部署多人共享服务，因此联网互通按钮不可开启，也不会上传偏好。共享接入适配器已准备，后续可通过 `PREFERENCE_HUB_URL` 配置服务（HTTPS；本机测试允许 HTTP localhost），并可用 `PREFERENCE_HUB_TOKEN` 配置访问令牌。服务接口：`GET /suggestions?q=...` 返回 `{suggestions:[{term,count}]}`；`POST /events` 接收 `{eventId,words}`，应按 eventId 去重并汇总词频和共现。只有用户同时开启共享与个人记录时，才发送完成运行产生的词条事件；不发送原始提示词、来源 URL 或摘录内容。关闭个人记录但开启共享时只读取共享建议。共享服务端仍需另行实现用户隔离、撤回删除、防刷及持久化，不能把接入适配器视作已经上线的多人网络。

## 深度模式

编辑搜索任务或单 URL 任务，勾选“开启深度模式”，可独立开启“正文中的超链接”和“相关推荐链接”，至少选择一项。默认深入1层、总计最多20页，可设1至3层、1至50页。起始文章为第0层，下一跳为第1层。已有任务默认不开启深度模式。

搜索任务沿用已指定网站及其子域名范围，最多取5个初始候选文章继续深入；单 URL 任务限起始网址同域及子域。不会自动扩展到其他网站。文章相关性按搜索主题检查；单 URL 模式可以另填主题关键词，留空时按首篇标题分词检查。不相关页面不再深入。

页面总数包括成功、失败和重复页面，搜索任务同时受每次摘录篇数限制。去重与访问记录防止循环跳转；之前已保存但内容不变的页面仍可发现后续链接。达到上限时，明细列出未处理的链接。明细和报告显示发现类型、层数、上级页面链接，便于追溯。

推荐区域只用于发现链接，其中的广告、评论和推荐标题不会加入文章正文。仅识别静态 HTML 中的推荐模块和链接，网站需要 JavaScript、“换一批”或登录才能展示的链接暂不支持。不同网站结构不同，推荐模块可能漏检。

## 查询链接与主题词库

“本次查询明细”中，每条成功、重复、失败或不匹配记录都会显示可点击的标题和完整 URL，在新标签页单独打开。入口失败记录也带链接，搜索引擎失败记录可打开对应搜索页。报告来源链接也可以直接打开。

在搜索提示词中输入“显卡”等主题后，下方会显示联想词表及推荐网站表。点击“加入”才会把词加入提示词；点击“加入网站”才会添加到允许搜索范围，重复网站不会添加，仍最多5个来源。推荐是静态词库匹配，不是 AI 实时推荐，不保证网站能被自动摘录。

左侧“主题词库”支持新增、编辑和删除主题，可维护触发词、联想词和推荐网站。保存到本机 data.json，重启仍保留，修改词库不会修改已有任务。预置显卡、人工智能、处理器与芯片三个主题，内置官方推荐网站于2026年11月1日核对过页面；网站后续仍可能改版或调整访问限制。编辑预置词条时，未改动的词和网站保留其分类、用途说明；新加入的条目标记为自定义。

## 搜索任务（外层）

点击“新建任务”，默认选择“搜索主题 → 自动摘录多篇文章”。填写主题提示词、允许搜索的网站、每次最多篇数和每日时间。执行后程序自动发现候选链接、检查正文关键词、去重、摘录图文并逐篇生成报告，原来的单 URL 摘录仍可单独使用。任务卡显示本次找到、处理、新存、重复、不匹配和失败数量，并提供明细。部分文章失败时保留已成功的报告。

这一版不调用 AI，提示词会分词后按关键词检索，并非语义理解。建议填写具体关键词，如“新能源 电池 技术进展”。每个任务最多5个来源、每次最多30篇；最多检查60个候选链接，不递归抓取整个网站，也不保证找到全网或站内全部文章。

来源每行一个，支持首页、新闻列表、RSS 或站内搜索 URL。站内搜索用 `{{query}}` 代替关键词，例如 `https://example.com/search?q={{query}}`（需要替换成目标网站真实有效的搜索地址）。普通来源会读取页面文章链接，同时尝试 Bing 的 RSS 搜索补充发现；只有指定域名和子域名内的文章才会被摘录，重定向超出范围也会停止。搜索引擎可用性和索引覆盖不保证，没有发现结果时会明确提示。向搜索引擎发送的仅是主题和网站范围。搜索型任务后台运行，关闭页面不影响已启动的任务，但本地服务须保持运行。

正文检查为关键词规则，可能存在漏检或误匹配。文章配图和广告评论过滤沿用 URL 摘录单元；同一文章内容与模板未变时不重复存储。来源改动后仍沿用已抓取链接去重；修改模板会允许新版本报告生成。

双击 `启动.cmd`，浏览器打开 http://127.0.0.1:3817 。需要 Node.js 22 或更新版本；本机已有的 Codex Node.js 运行环境也会自动使用。启动窗口请保持打开。

不要直接双击 `index.html`，也不要通过 file:// 文件地址操作。工具必须连接本地服务才能保存任务。新版会等待服务启动成功后再打开浏览器；误开 HTML 时会显示启动指引。

1. 点击“添加网页”，输入名称和完整网页地址（支持 HTTP/HTTPS、IP、端口）。
2. 设置每日时间，修改文字模板，保存任务。
3. 点击“立即摘录”，在“摘录报告”查看结果并下载 TXT。
   自动采集会优先提取文章正文区域，过滤常见导航、广告、评论、分享与推荐模块。不同网站结构不一致，无法保证完全过滤，复杂页面仍需核对。文章内最多20张配图会保存到本机 media 文件夹；每张最多5MB，每份报告图片合计最多40MB。下载失败的图片会标记原因，不阻止文字报告生成。图片按原始顺序展示在正文后，不进行图片文字识别。可下载“图文 HTML”，图片内嵌在文件里便于离线查看；TXT 仅含文字。
   报告每5秒检查更新；内容未变化不重绘列表，内容变化时保留报告展开状态。旧报告不自动修改，重新运行任务会按新提取规则生成报告。
   如果网站禁止自动采集，可以在任务卡点击“粘贴正文”，手动复制文章标题和正文，按同一模板生成报告。报告会标记为“手动导入”；此功能不访问原网站，不改变每日采集配置，也不会清除自动采集的错误状态。对禁止采集的来源可通过编辑任务关闭每日采集。
4. 每日任务按电脑本地时区执行。工具启动时，当天已到时间但未执行的任务会补跑一次；不会补齐历史日期。每日任务失败后不会在当天反复自动触发，可手动重试。

模板字段：`{{title}}`、`{{time}}`、`{{url}}`、`{{text}}`。普通文字替换，无 AI 分析、无付费模型和 API 密钥。编辑模板后允许重新生成同一网页。

普通 HTML 页面与纯文字页面可用；不执行网页 JavaScript，不处理登录、验证码、PDF 或新闻列表下的文章追踪。首页资讯可能只得到列表文字，应填写文章详情页以取得正文。正文提取为轻量规则，复杂页面可能夹杂菜单或漏掉内容。默认直接请求网页，不因 robots 规则停止。可在任务编辑中勾选“遵循网站 robots 规则”；勾选后检查 Allow/Disallow，无法确认规则时会显示错误。原有未配置此选项的任务也默认直接采集。

最多读取 2 MB 页面，单次请求超时 15 秒，临时失败最多尝试 3 次。正文和标题都相同时不重复生成。所有任务和历史保存在旁边的 `data.json`，可备份整个文件夹。删除任务保留原有报告。此版本未提供报告删除与存储自动清理。

服务仅监听本机 127.0.0.1；支持你有权访问的内网网页，但不要将服务端口转发到公网。文字及模板保存在本机，不发送给模型服务。网页内容不会作为代码执行。

关闭启动窗口即停止服务。电脑关机、睡眠、断网时无法采集。HTTPS 证书错误会直接报错；IP 地址请包含正确协议和端口。

如默认端口被占用，可在命令行设置 PORT 后运行 `node server.cjs`，再用对应端口打开浏览器。

## AI 分析与报表
左侧“AI 设置”可选 DeepSeek、OpenAI、通义千问、智谱、本机模型或自定义兼容接口。填写完整 Chat Completions 地址和账户可用模型名称；密钥仅保存在本次服务内存，重启后重新填写。远程分析需勾选允许发送摘录文字。接口测试会发出一次模型请求，可能产生费用。

“分析报表”按报表大类组织数据小类，支持编辑小类名称、分析方法和问题。预置资讯整理、产品对比、趋势风险、数据指标四类。可先使用无密钥的基础整理，或调用已配置模型。分析表区分原文事实、程序统计、AI推断和数据不足，提供来源链接、逐字引用及限制，支持导出 CSV。

每份分析最多纳入20篇去重文字资料，每篇最多8000字符、合计60000字符；结果显示未纳入篇数。AI引用通过原文存在性核验，不等于独立事实核查。缺少同口径时间点时不强行计算趋势、预测或因果。任务编辑中可开启采集后自动分析；分析失败不影响已有摘录。

### AI 分析超时与重试
文字分析按最多3篇、约12000字符一批调用，默认单批等待300秒，可在AI设置改为60至600秒。已完成批次即时保存；若后续失败，报表显示“部分完成”，可用“重试未完成批次”继续。分批结果未做跨批综合判断，不当作全样本结论。重试可能产生新的模型调用费用，已完成批次不会再次调用。

### AI 过程可视化
接口测试会显示请求发出、服务响应（HTTP状态）、响应接收字节数及模型实际返回的测试文字。分析报表提供真实批次进度、逐批资料链接、计时与结果保存状态。计时增长不代表连通成功；等待响应期间无法确认服务端是否正在生成。过程通过本地状态定期刷新，不展示模型内部思考。服务重启会清除临时密钥，未完成操作可重新测试或重试。

### 正式排版报告下载
每份已生成报表现在直接显示真实数据排版预览，采用白底与淡色内容分区，可打开完整报告，下载PDF、PNG长图、HTML。无需重新调用AI，已有报表也可导出。核心要点为已有有效分析结果前三条，并非额外综合判断；其余分区按所选数据小类组织，保留事实/推断标记、引用、待核实项目和来源目录。超长报告超过30000像素时请使用PDF或HTML。CSV明细仍保留。

### AI自动补证与正文整理
正式排版正文不再展示missing行、引用校验失败、数值不一致等内部处理信息；这些仍保留于应用的折叠明细与处理记录。新AI分析对未通过的行自动追加一次基于本批原文的补证修正，修复后仍须通过相同引用与数值检查。无法解决的项不进入正式结论。已有报表可选择“重新分析并自动补证”；此操作会重新调用模型。自动补证最多一次，不保证原文不存在的数据能够补齐。

### 数值校验与原文回退
数值使用规范化后的完整数字比较。AI改写包含引用不支持的数值时，若逐字引用本身确实存在于保存原文，正文回退为原文摘录，不整项丢弃，也不补充原文未披露的年份或参数。多段证据分别保留上下文，不合并测试条件。已保存的“数值与引用不一致”项目会在服务启动时按相同规则修复；无真实引用的项目仍不进入正文。

### 生成方案公开（测试版）
左侧“生成方案 / 实现”公开处理流程、当前分析与补证提示词、模型参数、数据小类定义及实际源码。分析页“查看本次生成方案”可在调用前查看选中指标和各批完整需求（不调用AI）。每份报告有“查看本报告执行记录”，新生成任务保存每次实际请求（密钥隐藏）、校验前模型返回、补证及最终结果，可下载JSON。历史任务未保存的请求不作还原。执行记录含采集正文，保留在本机。该界面展示应用执行记录，不涉及模型内部思考。
