# 轻摘 v1.0.0 · Windows 桌面版

## 使用
1. 解压整个压缩包到可写目录，双击 `轻摘.exe`。无需另装 Node.js。
2. 启动界面会依次显示本地服务、浏览器和工作台的加载进度。
3. 在顶部“内置浏览器 / 登录”输入网址或关键词。需要登录时由你在网站内完成登录；然后回工作台运行任务，或选择文字任务后点击“摘录当前网页”。
4. 原有任务：在“版本与更新”选择“导入旧版资料目录”，选择包含旧版 data.json 的文件夹，关闭软件，运行“导入旧资料.cmd”，再启动。本机旧版数据不会自动发送或打入发布包。

适用于 Windows 10/11 x64，需要 .NET Framework 4.8 和 Microsoft WebView2 Runtime。缺少 WebView2 时从微软官方下载并安装：https://developer.microsoft.com/microsoft-edge/webview2/ 。某些网站会限制嵌入式浏览器登录；本版本不保证所有网站都接受 WebView2。

## 数据与登录
任务、报告、图片、视频、更新备份和浏览器资料在软件旁 `UserData` 目录。更新包不含、不替换这个目录。网站登录资料保存在本机 BrowserProfile；与日常浏览器分离。退出账号请在网站内操作。AI密钥目前仅保留在本次服务内存，重启需重填。浏览器桥接使用每次启动随机生成的本机会话令牌，仅供此程序调用。

## 更新
“版本与更新”→“检查更新 / 打开更新程序”。首次填写 GitHub 更新清单地址，例如：
`https://github.com/你的用户名/你的仓库/releases/latest/download/latest.json`

独立更新器显示下载百分比、已下载/总大小、速率和执行阶段。下载完成后核对大小及 SHA-256，再解包并验证包内版本、路径与必要文件；通过后才关闭主程序。主程序退出会结束其子进程，再替换文件。替换失败会尝试回滚，并保留 `UserData/updates` 中的备份与日志。更新完成可选择是否重启。

还没有配置真实 GitHub 仓库时，无法在线取得新版本。随包提供的 latest.json 中 OWNER/REPOSITORY 是占位内容，发布前必须改为自己的仓库。

完整性哈希用于发现损坏或与清单不一致的包，不能替代代码签名；只配置你信任的更新地址。当前为未签名测试版本。

## 格式与透明度
分析报表可下载 PDF、PNG、HTML；“生成方案 / 实现”公开提示词、程序规则、源码和新报表实际执行记录。程序关闭后每日任务暂停，不安装后台常驻服务。

## 视频及图文工具
本次桌面发布包包含原有 app/tools 工具。浏览器登录态已接入网页正文及图片读取；需要会员权限的视频下载仍取决于网站及下载器的支持，不保证单凭内置浏览器登录就能下载。

### SearXNG 搜索
编辑文字搜索任务时，可在“补充搜索引擎”选择 SearXNG，并填写已启用 JSON 接口的服务地址。程序将搜索主题和指定网站域名发送给该服务，再按网站范围过滤并去重。没有可用服务时，任务明细显示连接错误；指定页面发现仍可继续。公共实例可能限制JSON接口或请求频率，不保证过滤所有推广和低质量网页。
