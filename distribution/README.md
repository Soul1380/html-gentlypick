# 轻摘 Windows 桌面版

解压到可写目录后，双击“轻摘.exe”。需要 Windows 10/11 x64、.NET Framework 4.8 和 Microsoft WebView2 Runtime。任务、摘录、下载文件及浏览器资料保存在同目录的 `UserData` 中，请保留该目录。

## 检查更新

启动后程序会在后台检查 `Soul1380/html-gentlypick` 的正式 GitHub Release，也可以在“版本与更新”中手动检查。发现新版本后显示当前版本、新版本和发布说明；只有选择“立即更新”才开始。

独立更新器先下载 Windows 更新包，检查 GitHub 提供的大小和 SHA-256，解压到暂存区并检查版本及路径，之后请求当前轻摘退出、等待已识别的相关进程结束，再备份、替换和核验程序文件。更新期间数据目录不包含在发布包中；失败时会尝试恢复旧文件并保留日志。日志通常位于 `UserData/updates/logs`，主目录不可写时会使用系统临时目录并提示。

更新源需要可访问 GitHub，正式 Release 必须包含名为 `LightExcerpt-win-x64-update.zip` 的附件及 GitHub 提供的 SHA-256 摘要。下载未通过验证或无法确认进程退出时不会开始替换。SHA-256 用于核对下载内容；本版本不包含代码签名。

## 从旧版迁移

此前 1.0.0 的更新器使用不同的更新清单格式；首次迁移请先关闭旧版，备份 `UserData`，再使用 1.0.1 完整包安装。不要把自己的 `UserData` 打包上传。旧版资料也可通过软件中的“导入旧版资料目录”导入。

## 视频工具

发布构建需要 yt-dlp、FFmpeg 和 ffprobe；构建脚本会从固定的官方版本获取并校验文件，或者通过 `-ToolsDirectory` 使用已校验的本地副本。视频是否可下载仍取决于来源网站和账户权限。
