# 轻摘 v1.0.10

- 新增 B 站普通视频评论摘录，支持时间/热度排序、数量限制、部分回复关系与 CSV 导出。最多采集五页，不代表全量评论；不支持电影评论。
- 新增网页附件摘录，可查找 PDF、Office、CSV、TXT、ZIP 直接链接，按数量和大小限制下载，归档并导出 CSV。暂不支持动态按钮下载或附件正文解析。
- 支持 B 站电影和番剧 ep/ss 播放链接；目标跳转到其他视频时停止，避免误采推荐内容。
- 视频任务可选择 Chrome/Edge 登录状态，默认关闭；试看权限会明确提示，下载前检查合并所需空间，并保存可用字幕。
- 保存目录和 Python 路径支持“浏览”按钮及回车选择；取消选择保留原值。

已有数据保留。浏览器登录读取可能受进程占用或系统加密机制限制。网站接口变化、登录和观看权限限制仍可能导致采集失败。

验证：本地附件采集、下载、404 部分失败、重复运行、大小限制、CSV 转义；浏览器表单类型切换与保存；真实 B 站评论采集、归档与导出；原生路径选择程序编译。
