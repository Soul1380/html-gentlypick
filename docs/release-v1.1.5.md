# 轻摘 v1.1.5

- 本地 Whisper 按实际转写片段更新进度：已识别时长、总时长、百分比、最新识别文字与累计用时。
- 提取音轨按实际处理时长更新进度；文字整理显示当前批次与累计用时。无法计算阶段保持等待动画，不伪造百分比。
- 移除视频转写与分析的固定五分钟运行限制，保留手动取消；取消会终止本地转写进程，保留已经识别的片段。
- 软件在运行时读取处理器线程、物理内存和当前可用内存，为本地模型列表及视频语音模型列表添加“推荐”标签，不显示推荐理由。Whisper 按当前 CPU/int8 运行方式评估。

运行时长限制与导入文件限制分别处理：本版保留视频 20 分钟 / 300 MB 的导入范围。
