# 轻摘 v1.1.9

- 资讯、产品对比、变化观察和数据解读分别采用通俗的讲解顺序，不再统一堆成结果表。
- 取消模型解释的200字约束及结果正文1500字符、说明1000字符的截断；视频说明也取消人为截断。
- PDF正文以完整中文段落为主，术语应解释，原文只保留查看入口，不再自动追加英文引用或证明附录。
- 增加原文段落编号映射，模型只选择原文编号，减少把翻译内容当逐字引用的问题。仍拒绝无效编号和未对应到资料的内容；编号对应不等于事实已经独立核实。
- 兼容小模型将阅读章节误写为指标ID的已知格式混淆，保留原始调用记录。
- 对比和数据报告分别保留原文参数表及统计结果，并要求AI解释数字含义，避免把不同条件的数据混算。
- 四类演示样张全部更新，演示内容不写入用户报告。
- 使用本机已安装的8B模型实际测试：IQ4_XS初次调用暴露翻译引用问题；Q4_K_M直接撰写用时56秒，完整软件流程用时28秒。实测正文未人工改写，本地小模型仍存在术语、细节和推断质量不足，不能等同于人工样稿质量。
