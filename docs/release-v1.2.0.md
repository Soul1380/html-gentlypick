# 轻摘 v1.2.0

- 分析使用全部已保存正文，长文分段读取，不再按每篇8000字符截取。不同分段不混用原文编号。
- 先整理原文信息，再单独撰写各阅读章节；写作不强制JSON格式，不按字数截断。按章节检查完成情况，失败重试保留已完成章节。
- 本地小模型误写其它章节时，提取对应章节；正文支持基本标题、段落和加粗排版。原始返回保存在执行记录中。
- 新增Excel导出：原生图表、带筛选的Excel数据表、数值和日期类型、关联公式、原文与讲解。无需电脑另装Python或在线服务。
- 依据同一指标、单位、统计范围及日期选择柱状图、折线图、饼图、直方图或散点图；条件不足时保留表格。直方图区间和频数通过公式关联原始数据。
- 报告中可粘贴或导入CSV，填写指标、单位、范围和用途；来源文字含有明确元数据及CSV数据表时也可自动识别。没有明确统计含义的零散数字不会硬拼成图表。
- PDF、HTML和Excel使用同一数据计划，完整数据保留在Excel中，图表为可编辑对象。

验证：五类图表选择与边界、Excel原生图表/表格/公式、修改源值和标签后的重算、直方图区间与频数重算、CSV界面导入与导出、PDF图表、完整长文分段、章节中断恢复、现有UI和共享组件检查。
本地实测仍使用已保存的正文摘录，模型会有表达和事实理解方面的局限；实际样本及调用记录单独提供。
