# 轻摘 v1.2.1

- 新增停止摘录，取消当前采集请求与下载子进程，保留已保存结果。
- 新增档案单篇、多选、按当前结果或整个任务清除，可选择删除本地文件。
- 新增任务和档案右键菜单，支持运行、停止、定时开关、编辑、复制和清除。
- 统一正文选中规则，Ctrl+A 限定在当前正文或输入框。
- 保留共享文件，阻止运行中任务清除档案，避免采集完成后重新写回。

验证：实际 HTTP 取消、子进程停止、清除确认与持久化、共享文件保护、主界面与共享组件、视频集成及深色登录界面回归通过。

- 修复内置浏览器读取较大视频网页时被旧 2MB 限制阻止的问题；改为较大网页确认提示，默认不设硬性上限；可在设置中调整询问阈值、启用硬性上限。
