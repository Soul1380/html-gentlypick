# 轻摘 1.0.1

- 优化监测任务和摘录档案的布局，精简重复说明。
- 增加独立的 `Updater.exe`：启动时后台检查 GitHub 正式版本，也可手动检查；确认后显示下载进度和速率。
- 安装前核对下载大小、GitHub 附件 SHA-256、包内版本及文件路径；确认轻摘和已识别的相关进程退出后，备份、替换和验证程序文件。
- 遇到安装失败时停止并尝试回滚；日志记录更新步骤。更新包不包含 `UserData`。
- 1.0.0 使用不同的更新方式，首次迁移请备份 `UserData` 并使用完整的 1.0.1 安装包。

此版本尚未在真实 GitHub Release 完成在线升级验证；程序尚未代码签名。
