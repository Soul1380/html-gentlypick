# 轻摘 v1.0.9

## 视频分析
- 视频分析集成到工作台，支持打开已采集的视频或导入本地视频，并修复导入后不加载的问题。
- 支持本地 Whisper 转写、自动查找已有运行环境；转写和分析进度可保存，中断后可恢复并继续未完成的分析。
- 调整视频分析和本地模型页面的深色模式。

## 搜索与报告
- 分析报告改为选择资料、报告类型和生成三个步骤，支持选择不同任务的文字摘录。
- 搜索任务可选用 AI 扩展搜索词、筛选结果，并支持使用本地 Ollama 模型分析。
- 主题词库支持 JSON 导入、下载样例和复制 AI 整理要求。

## 使用体验
- 改进本地模型选择和查找、文件夹路径选择，以及任务运行状态显示。
- 新建任务等弹窗支持 Esc 关闭；教程和实现说明移到顶部导航。
- 修复模型下载取消后仍保留本次未完成文件的问题。

## 当前限制
- 视频分析目前支持不超过 20 分钟、300 MB 的文件。
- 本地模型需要安装可用的运行环境；云端模型需要自行配置服务。
- 模型生成内容可能有误，请结合原文或视频核对。
