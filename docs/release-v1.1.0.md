# 轻摘 v1.1.0

本版统一资料选择、文件路径、模型选择与二级窗口，解决逐篇勾选繁琐、返回后输入丢失，以及各页面重复实现浏览控件的问题。

- 按摘录项目分组选择资料，支持整组、搜索结果批量选择和部分文章选择。明确选择的资料不再被 20 篇上限截断，AI 按内容分批；单次最多选择 1000 篇，每篇最多取前 8000 字。
- 模型选择共用可搜索的大窗口，少量设置保留普通下拉框；路径与文件输入使用右侧 Enter 入口。Windows 文件夹窗口带地址栏、可调整大小；工作台、安装程序和旧资料导入统一使用。
- 模型管理覆盖打开，一键返回或 Esc 保留原页面；侧栏切换和后台刷新保留当前运行内的输入草稿。密钥不写入草稿或浏览器存储。
- 模型源文件与 Ollama 存储位置提供直接打开目录入口；状态统一使用文字与颜色。
- 保留 Ollama 的原模型目录，刷新只读；Whisper 显示真实下载字节、速度及安装步骤。
- 顶部原生按钮区分鼠标与键盘焦点，避免鼠标操作残留焦点框。
- 提供共享组件、配置扩展接口、使用文档与项目开发规范，后续特殊选项通过配置或组合扩展。

验证覆盖工作台 8 页、模型管理、视频分析、深浅主题及窄窗口；项目 30 篇整组选取及后台完整接收；AI 和视频输入往返保留；路径回车与跨窗口桥接；模型刷新、导入和已有目录发现；Whisper 进度、失败、取消和完成；采集、分析和存储回归。原生程序及安装程序编译通过，实际 Windows Common Item Dialog COM 接口可用。系统目录窗口的人工操作与不同显示缩放尚未逐一实机验证。

首次安装可使用安装程序。已有安装使用同目录提供的升级脚本，保留 UserData；正在下载、采集或分析时不会强行关闭程序。
